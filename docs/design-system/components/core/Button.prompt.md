Action button for every CTA on AI4Impact surfaces; pick the variant by background (light page vs dark hero).
```jsx
<Button variant="primary" size="sm" icon="arrow-up-right">Explore course</Button>
<Button variant="outline" size="sm">Enrol in this course</Button>
<Button variant="light" size="lg" icon="arrow-right">Explore career tracks</Button>
<Button variant="dark-ghost" size="lg">Book free career guidance</Button>
<Button variant="promo" size="sm" icon="arrow-right">Register free</Button>
```
Arrow icons: `arrow-right` = go to section/page, `arrow-up-right` = open course detail. `link` variant for quiet text actions ("View prerequisites").
